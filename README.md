# Threads Enhancer

A Google Chrome Extension that enhances your browsing experience on **Threads** ([threads.net](https://www.threads.net)) by adding clean, native-looking utility buttons and custom interface components.

---

## Features

- 🌐 **Open in New Tab**: Directly open any post in a new browser tab with a single click.
- 🔗 **Copy Post Link**: Quick-copy post URLs directly to your clipboard.
- ⬆️ **Back to Top**: A stylish, floating button to quickly scroll back to the top of your feed (styled to perfectly match the native "Add New Post" floating button on Threads).

---

## Customization

The extension includes a convenient options popup. Click on the extension icon in your toolbar to:

- Enable or disable individual buttons (**Open in New Tab**, **Copy Post Link**, **Back to Top**).
- Change the **Action Order** of injected utility buttons.
- Select the **Theme** for the settings panel (**System**, **Light**, or **Dark**).
